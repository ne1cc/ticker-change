Universe Ranking & Backtest Single-Ticker Scanner Screener
Methodology
{# `rf_annual` only rides along on the universe tab; elsewhere the copy degrades to naming the assumption without quoting a number rather than hardcoding one that could drift out of sync with RF_ANNUAL. #} {% set rf_pct = data.rf_annual if data else None %}
{% if strategy_id == 'sma_trend' %}

1. 50/200 golden-cross trend filter

Each ticker is scored by the spread between its 50-day and 200-day simple moving averages, expressed as a percentage of the 200-day. A positive spread is a golden cross (the classic long regime); a negative spread is a death cross. Because the score is a moving-average distance rather than a return, it reacts more slowly than a 12-1 return and turns over less.

{% elif strategy_id == 'rsi_reversion' %}

1. Connors RSI(2) Mean Reversion

Exploits short-term oversold pullbacks inside secular uptrends. Tickers are screened for price > 200-day SMA, entering long when 2-day RSI falls under 15. The exit triggers aggressively when RSI crosses above 70 or price closes above the 5-day SMA.

{% elif strategy_id == 'buyer_signal' %}

1. Multi-Factor Composite (Buyer Signals Alpha)

Blends Macro Trend (40% weight on 50/200 SMA), Intermediate Momentum (35% weight on 3M/6M returns), and Volatility Quality (25% weight on inverse 1Y vol) into a 0–100 confluence rating. Holds long when score ≥ 55 and pivots to cash below 45.

{% elif strategy_id == 'dual_momentum' %}

1. Dual momentum: relative rank, then absolute gate

Names are ranked on the same trailing 12-month return excluding the most recent month, then put through a second, absolute test: a name is only held if that return clears a cash hurdle. The hurdle is the same fixed {% if rf_pct %}{{ rf_pct }}% {% endif %}annualised risk-free assumption this page already uses for Sharpe and Sortino, scaled down to the 11-month scoring window — it is a standing assumption, not a live T-bill quote. A top-ranked name that fails the hurdle is left in cash rather than backfilled from rank 6, so the portfolio genuinely de-risks when the whole universe is weak.

{% else %}

1. 12-1 cross-sectional momentum

Each ticker is ranked by its trailing 12-month return, excluding the most recent month (Jegadeesh & Titman, 1993). Excluding the last 21 trading days removes short-term reversal effects driven by liquidity and market-impact noise rather than the underlying medium-term trend. There is no absolute gate — the top 5 are always held, even in a broadly falling market.

{% endif %}

2. Risk-adjusted ranking

{% if strategy_id == 'sma_trend' %} The Risk-Adj column divides the SMA spread by trailing 1-year annualised volatility, so a wide spread on a wildly volatile name isn't flattered. Note the leaderboard itself still sorts on the raw spread. {% else %} The Risk-Adj column divides the 12-1 return by trailing 1-year annualised volatility, so a name isn't flattered purely for being erratic. Note the leaderboard itself still sorts on the raw 12-1 return — the risk-adjusted score is shown alongside it, and it is the Screener's Min Risk-Adjusted Score filter that actually acts on it. {% endif %}

{% if strategy_id == 'sma_trend' %}

Rank, not sign, decides the holdings. Unlike Dual Momentum there is no absolute gate here: the rotation holds the top 5 by spread whatever that spread is, so in a broad downtrend a name badged Buy can sit at a negative spread — a death cross the backtest is genuinely long, because it was still one of the five least-bad names. The single-ticker backtest is the one that goes to cash below zero.

{% endif %}

3. Universe backtest

The universe chart simulates an equal-weight portfolio of the top 5 ranked names, rebalanced monthly, with a 7.5 bps round-trip cost charged on turnover at each rebalance. {% if strategy_id == 'dual_momentum' %} Weights stay fixed at one fifth per slot, so slots that fail the hurdle are held as uninvested cash and drag the portfolio toward flat instead of concentrating it into the survivors. {% endif %}

4. Single-ticker backtest

The single-ticker view runs a time-series variant on that same ticker, under the same cost assumption: {% if strategy_id == 'sma_trend' %} long while its 50-day SMA is above its 200-day SMA, flat (cash) once that crosses back down. {% elif strategy_id == 'dual_momentum' %} long while its own 12-1 return clears the cash hurdle, flat (cash) otherwise — a higher bar than simply requiring a positive score. {% else %} long when its own 12-1 score is positive, flat (cash) otherwise. {% endif %}

Strategy Logic & Execution Blueprint

{% if strategy_id == 'rsi_reversion' %}

Connors Pullback Mechanics: Entries require a macro uptrend regime (Close > 200-day SMA) coupled with severe short-term exhaustion (RSI-2 < 15).

Exit Discipline: Position closes cleanly when either the 2-day RSI rebounds above 70 or price moves back above the 5-day SMA.

{% elif strategy_id == 'buyer_signal' %}

Multi-Factor Weighting: Trend (40% weight on 50/200 SMA), Intermediate Momentum (35% weight on 3M/6M price velocity), and Quality Volatility (25% weight on inverse 1-year volatility).

Hysteresis Thresholds: Enters long when the composite score crosses ≥ 55. Drops to cash when score falls below 45 to prevent whipsaws.

{% elif strategy_id == 'sma_trend' %}

Drawdown Control: Exits to cash on the death cross (50-day SMA < 200-day SMA), avoiding catastrophic secular bear markets.

Lag vs Whipsaw Trade-off: Moving averages lag by definition, but eliminate noise compared to faster oscillators.

{% elif strategy_id == 'dual_momentum' %}

Cash Hurdle Filter: Must beat both the universe peers and the absolute risk-free cash hurdle to justify taking equity risk.

{% else %}

Classic Momentum: Capitalizes on 12-1 momentum drift while sidestepping extended 1-month reversal friction.

{% endif %}
